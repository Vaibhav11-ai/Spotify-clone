# Spotify Clone

A simple Spotify-inspired static web app built as a front-end prototype. This project contains a basic home page, registration form, and a users list page.

## Overview

This repository is a beginner-friendly project inspired by Spotify. It is currently a static HTML project and does not use the real Spotify API or backend services.

## Pages Included

- Home page (`index.html`)
- Registration page (`registration.html`)
- Users page (`users.html`)

## Features

- Navigation links between pages
- Registration form with name, email, password, and confirm password fields
- User listing table with sample data
- Lightweight static website structure
- Easy to run locally in any browser

## Project Structure

```bash
Spotify-clone/
├── index.html
├── registration.html
├── users.html
├── README.md
```

## How to Run

Since this is a static website, you can run it in either of these ways:

1. Open `index.html` directly in a browser, or
2. Serve it locally:

```bash
python -m http.server 8000
```

Then visit:

```bash
http://localhost:8000
```

## Tech Stack

- HTML5
- Vanilla JavaScript (optional future enhancement)
- CSS (can be added later for styling)

## Notes

This project is a learning/demo project and is not connected to Spotify's live services or data.
